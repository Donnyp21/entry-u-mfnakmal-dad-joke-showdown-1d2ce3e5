# entry-u-mfnakmal-dad-joke-showdown-1d2ce3e5 — Dad Joke Showdown

One dad joke for make.fun's "Dad Joke Showdown" bounty.

> I put my phone on airplane mode, and now it keeps telling me about its fear of heights.

Why it should earn the groan: the setup is an everyday phone
habit, the punch takes "airplane mode" literally, and it lands in
one breath with no explanation — a clean dad-joke turn that is not
one of the thousand-times-told ones. One sentence, 87 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only, no network, no
randomness) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `$MAKEFUN_OUTPUT`, then `/output`) and asserts the
competition's gate itself: one sentence, 1–200 characters. The joke
is a fixed string, so two runs produce identical bytes.
